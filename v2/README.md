# BITX v0.2：有交易的历史学习实验

用户要求扩充数据、改善order block识别和每日200美元达标率，并将零交易或交易过少直接定义为失败；本轮只使用免费公开数据。

## 结果

最后12个交易日平均每天3笔、共36笔，交易量门槛通过；交易净亏153.08美元，达标0/12，盈利目标失败。未启动实时学习或前瞻纸面交易。

毛亏37.88美元，佣金与点差滑点假设合计115.20美元；双倍成本净亏266.53美元。19笔分数触发交易净亏70.82美元，17笔截止点探索交易净亏82.26美元。记录探索交易是为了评估参与市场的代价，不把强制交易包装成盈利信号。

OB新独立首次触碰：接受4个成功1个（25%）；压力区：接受11个成功7个（63.6%）。同一批旧区域对照中，OB仍接受1个成功0个，压力区接受8个成功6个（75%）。本轮不能声称识别能力获得可靠改善。

## 做了什么

- 新增上市以来834根日线、清理后3458根小时线（494个完整交易日）；排除7个不完整小时交易日及当前尚未结束交易日。小时线预训练与5分钟执行严格分开。
- 五分钟历史没有新增日期：6个月5分钟请求收到公开API的60天限制错误；原始响应已保留。不访问付费数据、账户或密钥。
- 区域训练样本163→535，决策训练状态163个区域时点→2160个完整历史时点，每个计算5/15/30分钟三个动作结果。全样本865个区域触碰标签中，422个为独立首次触碰，重复触碰单列。
- 比较同结构小时预训练与BITX从零训练两种模型，各3个固定入场分位阈值，共6个候选。验证段选择从零训练版本，说明本轮小时预训练没有带来足以胜出的验证收益。
- 每天3个固定窗口；在窗口内按当前预测触发，未触发则截止点做标记的探索交易。窗口与最少交易门槛均在训练前登记，没有事后挑最优入场时间。
- 门槛：平均每天至少2笔，且至少80%交易日有交易；少于门槛即失败。盈利依旧单独验收，不用有交易代替赚钱。
- 交易5–30分钟、现金全额整数股；当天卖出资金不得重复用于日内交易；账户段内连续结算，不重置、不补充本金、无单日止损。
- 初始10000美元，每个窗口最多三分之一本金、上一根已结束K线成交量1%的参与上限，费用提前预留。

## 如何理解“学习”

本轮使用真实历史价格构造全部可评价时点的动作收益，让网络学习哪些状态、持有期更有利。历史中没被旧策略选中的交易也能提供训练标签。最终12天的模型参数保持冻结；其交易结果留作后续版本开发，不在同一份成绩中边看结果边优化。

当前是监督式状态/动作收益学习，尚非在线强化学习。最终12天已被v0.1查看，本轮仅为同日期比较；旧数据不会重新标为未见留出。

## 复现

```sh
cd bitx-orderflow-lab
OPENBLAS_NUM_THREADS=2 VECLIB_MAXIMUM_THREADS=2 python v2/run_v2.py --output results/v0.2-new-reproduction
python -m unittest discover -s v2/tests -v
python -m unittest discover -s tests -v
python v2/verify_v2.py
```

verify_v2.py对比已保存的v0.2和v0.2-reproduction。模型参数和报告（运行耗时除外）精确复现，22项测试通过。旧v0.1代码及结果保留不变。

下一版应优先检验入场方向和持有期的预测能力：本轮毛收益已经为负，单靠压低手续费不足以达到目标。需要保持交易量门槛，并用新的冻结规则对照探索交易与预测触发交易。

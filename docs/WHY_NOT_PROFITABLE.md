# 为什么没有达到目标

## 已验证的事实

v0.2最终12个历史交易日36笔，毛亏37.88美元，佣金23.04美元，假设价差和滑点92.16美元，净亏153.08美元；双倍成本净亏266.53美元。每天200美元目标达标0/12。即使将成本设为0，方向与持有期选择在这段数据上仍亏损。

17笔截止点探索净亏82.26美元；其余19笔预测分数触发净亏70.82美元。增加交易数量满足了活跃度要求，没有建立盈利优势。同样时点、资金和成本的固定5分钟持仓基准亏119.29美元，比模型亏得少33.79美元。

新增小时/日线没有增加五分钟执行历史；训练区域163增加到535，含相关的重复触碰。独立order block接受样本仅4个、成功1个。区域成功是预定义价格反应标签，没有人工确认的真实机构挂单标签。它与扣成本后的交易盈利并非同一个目标。

模型只有2,852参数，原训练仅需约1秒；计算资源不是本轮瓶颈。模型通过监督学习拟合区域结果和不同持有期收益，尚未实现在线强化学习。更长训练或更大网络的收益没有证据。

## 推进上的问题

此前把单轮实验执行完成视为交付终点，未建立符合用户持续目标的训练、复盘、版本更新和前瞻循环。失败汇报是必要记录，但汇报本身不能替代下一轮改进。

此前“失败策略不做前瞻”的约束加上缺少持续运行器，使实时纸面数据没有进入实验闭环。用户2026-10-22的新授权已允许Dot研究性运行失败模型并迭代；旧历史结论保持原样。

本轮有17笔强制探索，数量增加是执行规则的结果；不应将其解读为模型找到更多机会。训练数据已能给未被执行的动作构造收益标签，因此“没有模拟成交就完全不能学习”的理解也不准确。

## Dot 应优先检验的方向

1. 保持成本、资金、时间切分相同，先证明预测入场比固定时点/简单规则更好；毛收益为负必须正面处理。
2. 检查OB、压力区、BTC订单流各自增加了多少净收益预测能力；通过删除某组特征的对照测试，避免仅凭技术名称认定有效。
3. 保留足够交易，但把预测触发与探索分开比较；检验探索是否提供下一版有用样本，不能只增加亏损次数。
4. 新版本用独立未来数据评价；按版本持续维护所有亏损与成本，不在同一历史片段上无限调参找偶然赢家。

这些是下一步实验方向，尚未验证能盈利。当前交接只完成仓库整理；由Dot启动并验证云端持续工作。

# btc-v0.1 数学协议

## 固定假设

数据 Binance BTCUSDT；现货做多、无杠杆。三种策略在同一费用与退出规则下比较。
本金 10,000 USDT；每笔风险预算 0.25%，最大资金占用 25%；每日最多 6 次入场，连续 3 次亏损暂停至下一个 UTC 日；日损失阈值 1%。历史候选按独立资金回放。
分钟收盘后形成信号。历史下一分钟开盘进场；实时等新盘口并额外等待至少 1 秒。
默认最多持有 60 分钟，仍为日内研究；不使用原美股 2/3/7 日标签与门槛。

## 条件与确认时间

最近 20 根已经收盘的 K 线形成结构高 H、低 L。当前收盘越过 H 才确认向上突破。
趋势效率 `ER=(C[t-1]-C[t-21])/sum(abs(ΔC))`，ATR 使用过去 20 根真实波幅的平均值。
过去 60 分钟 VWAP=`sum(quote_volume)/sum(base_volume)`。
当前分钟主动买入量 B、总量 V：`D=(2B-V)/V`；相对量为当前 V / 过去 20 分钟平均 V。

1. **breakout 基准**：当前收盘突破过去 H。
2. **flow_pullback**：突破确认后，回找前 10 根中最后一根阴线，整根高低作为 OB。
   OB 最多有效 30 分钟，收盘跌破远端立即失效。
   后续 K 线与区域相交且收盘回到上沿之上，价格高于过去 VWAP，ER>0.15，D>0.2，相对量>1。
3. **sweep_reclaim**：当前最低价穿过过去 L，收盘收回 L，D>0.1，相对量>1。

同一种策略 15 分钟内最多产生一个候选。区域只能在突破确认后使用；高低点和回踩标记不回填到更早的决策。
这些数值为预登记的工程假设，不宣称由 Fabio 原版策略给出。

## 标签和交易成本

止损距离比例 `d=max(0.2%, 3 ATR / price, 到结构失效点的距离比例)`，大于 1.5% 时拒绝。
止盈距离 `2d`。未来最多 60 分钟，先碰止损/止盈或到期退出形成三分类标签。
同一分钟同时触及两边时按止损先发生；跳空低于止损按更差开盘价处理。
标签的实际退出时刻必须不晚于训练截止时间，跨训练/验证/测试边界的标签被清除。

对入场价 Pe、退出价 Px、数量 Q、单边费率 f：

```
gross = Q(Px-Pe)
fees  = f Q(Pe+Px)
net   = gross-fees
r_net = net/(Q Pe)
```

历史每边 1 bp 半价差 + 2 bp 滑点；压力检验把滑点提高到每边 4 bp。
实时按买入吃卖盘、卖出吃买盘走深度，每档最多使用显示数量的 10%，再加每边 2 bp 滑点。
可见深度不足时不制造成交；退出挂起并披露未解决仓位。不模拟限价单排队优势。
费用假设每边 0.10%，没有折扣。来源与日期写在 config.json；实际费用可能依账户而异。

仓位按风险预算与资金占用双重限制：

```
risk_per_notional = d + 2f + 2*slippage
notional = min(equity*0.0025/risk_per_notional, equity*0.25, cash/(1+f))
```

最终按 LOT_SIZE 向下取整；止损不是损失上限，跳价可超出预算。

## 条件概率模型

每个策略分四个条件格：D 是否≥0.2，ER 是否≥0.3。方向和分箱预先确定。
策略总体样本提供收缩先验，避免小格子被少数盈利样本主导：

```
p0 = (总体净盈利次数 + 1)/(总体样本数 + 2)
p_profit = (格子净盈利次数 + 20*p0)/(格子样本数 + 20)
mu_net = (格子净收益率之和 + 20*总体平均净收益率)/(格子样本数 + 20)
```

止盈/止损/到期概率使用相同 20 个等效先验样本的 Dirichlet 收缩，三者相加为 1。
父样本至少 50、格子至少 20，且 mu_net≥0.05% 才有主账本入场资格。
这是经验贝叶斯条件模型；相关样本数不等于独立样本数。该概率是待校准估计，不是置信保证。

初始 30 天训练，后 15 天选净收益最高者，最后 15 天评价选定策略；没有在看到最后 15 天后调参。
记录 Brier、按时间概率分箱校准、交易净收益、手续费、每日收益、回撤、价格基准以及滑点压力结果。
留出至少 20 笔交易、验证至少 20 笔、净收益为正、PF≥1.2、按日 bootstrap 平均净收益 95% 区间下限>0、
滑点加倍仍正、优于价格基准、已平仓回撤≤5%，全部满足才让 primary 自动开仓。
无交易意味着未验证，不等于模型成功。历史不合格的候选不进入前瞻交易，实时仅采集与记录信号。

## 新变量何时加入

当前历史数据真实含主动成交量，但不含盘口和单笔大单。因此这两类数据先记录，预测中不使用。
大单定义：过去最多 5,000 笔成交额的 99% 分位，至少 1,000 笔后启用；每 100 笔刷新，不使用当前成交更新自己的阈值。
CVD 从进程会话起点累计，发现 trade ID 缺口时重置并记录；分钟模型 Delta 使用官方完整分钟统计。
L2 记录 20 档失衡 `(bid_qty-ask_qty)/(bid_qty+ask_qty)`，不能把数量减少全部称为撤单。

先至少采集 3 天，再按日期做消融比较：固定策略 → 加大单 → 加盘口；每次只新增一组变量。
需要改善未用于拟合的每日净收益、成本压力结果，并检查概率校准。记录所有候选；不因短期一次获利就升级。
尚无对应样本时，禁止凭直觉给新增变量分配“历史验证过”的权重。
